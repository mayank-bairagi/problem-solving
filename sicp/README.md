# SICP — Structure and Interpretation of Computer Programs

Abelson & Sussman. Concepts worked through in Scala 2.12 (Scheme shown where it matters).

## Roadmap

1. **Ch 1 — Procedures**: substitution model, evaluation order, recursion vs iteration, orders of growth, higher-order functions
2. **Ch 2 — Data**: closures, abstraction barriers, hierarchical/symbolic data, generic operations
3. **Ch 3.5 — Streams**: delayed evaluation, infinite streams (`Stream`/`LazyList`)
4. **Ch 4 — Interpreters**: the metacircular evaluator, lazy evaluation
